# Уверенный хват

Учебный проект для студенческого кейса СТЕПЛАЙФ на SK Challenge 2026.
Программа распознаёт пять хватов и покой по поверхностной ЭМГ. Перед выдачей
команды проверяются качество сигнала, оценка модели и повторение решения.

Сейчас это программный прототип. Привод не подключён. Проведён первый опыт
на реальной записи одного участника NinaPro DB2 и отдельный запуск на искусственном
сигнале. Ограничение 100 мс пока не достигнуто.

## Результат первого опыта

Файл `S1_E2_A1.mat`, первые восемь каналов, окно 50 мс, шаг 10 мс.
Обучение: повторения 1, 3, 4. Настройка порогов: повторение 2. Тест: 5 и 6.
Пять хватов дают десять тестовых движений и 4574 окна с учётом соседнего покоя.

| Показатель | LDA | SVM |
|---|---:|---:|
| Точность классификатора | 48,7% | 55,4% |
| Macro-F1 | 0,432 | 0,500 |
| Отказы после проверки | 94,9% | 66,1% |
| Ошибки среди принятых команд | 49,1% | 24,4% |
| Движения без правильной команды | 3 из 10 | 2 из 10 |

У SVM число ошибочных переключений уменьшилось с 535 до 43. Но одновременно
были отклонены две трети решений, а медианное время до первой правильной
команды выросло со 175 до 225 мс. Это не готовое управление протезом.
Порог отсекает часть ошибок, но не исправляет слабое распознавание.

Отчёт: [PDF](docs/report.pdf) или [текст](docs/report.md).
Презентация: [семь слайдов](docs/presentation.pptx).

## Запуск

Проверено на Python 3.12. Требуется Python 3.10 или новее.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
python -m pip install --no-deps -e .
python -m unittest discover -s tests -v
```

Для искусственного примера данные скачивать не нужно:

```sh
grip-experiment --output results/local_synthetic
```

Для повторения опыта на настоящей ЭМГ:

```sh
python scripts/download_db2.py
grip-experiment --data data/S1_E2_A1.mat --output results/local_db2_s1
```

Скрипт скачивает официальный архив участника S1, около 448 МиБ, и извлекает
упражнение E2. Данные не входят в репозиторий. Описание и условия использования
нужно смотреть у [NinaPro](https://ninapro.hevs.ch/instructions/DB2.html).
Контрольная сумма использованного MAT-файла записана в `metrics.json`.

`results/db2_s1` и `results/synthetic` содержат сохранённые результаты первого
эксперимента. Для своих запусков лучше использовать отдельную папку.
Время вычислений зависит от компьютера и фоновых процессов.

## Что находится в коде

- `data.py` читает DB2 и выбирает движения 19, 32, 34, 20 и 27. Остальные
  движения не склеиваются. Искусственный пример нужен только для отладки.
- `processing.py` содержит причинный фильтр, временные признаки и простую
  проверку качества канала.
- `control.py` принимает оценки классов и возвращает команду либо запрет.
- `experiment.py` обучает LDA и SVM, выбирает параметры на валидации и
  проверяет четыре способа передачи команды на тесте.
- `tests` проверяет логику отказов, пропуски данных, отсутствие доступа к
  будущим отсчётам, загрузку и разделение данных.

Сигмоидная калибровка выполняется внутри обучающих повторений с GroupKFold(3).
Тестовые окна, включая переходы, не используются для настройки. Это проверка
на отложенных повторениях одного человека, а не на новых людях или визитах.

## Как читать метрики

Точность и macro-F1 относятся к ответам модели до проверки команды.
Отказ означает `command = None`, а не правильное распознавание покоя.
Ошибочное переключение — изменение принятого класса на класс, не совпадающий
с текущей меткой записи. Это событие программы, не физическое движение мотора.

Время реакции отсчитывается от `restimulus` до первой правильной команды внутри
движения. Пропущенные движения приводятся отдельно и не входят в медиану
успешных ответов. Время связи и механики не измерялось. Время вычисления
классификатора не равно полной задержке системы.

Параметры первого опыта выбраны по функции потерь, которая штрафует ошибки,
отказы и пропуски движений. Она не задаёт жёсткого ограничения на отказы.
Это одна из причин, почему выбранный режим нельзя сразу использовать в кисти.
Для следующего опыта нужны явные ограничения на отказы и время реакции,
а также новые тестовые данные.

## Подключение к приводу

`inhibit = True` должен запускать предусмотренную контроллером остановку
движения. Просто перестать отправлять команды недостаточно: старая команда
сжатия может продолжить выполняться. Класс `rest` не означает раскрытие кисти.
Удерживающее усилие, остановка и раскрытие задаются отдельно для механики.

Нужен независимый таймер отсутствия команд на стороне привода. Если данные
полностью перестали приходить, Python-функция `update` сама не вызовется.
Система не защищает от всех ошибок: несколько уверенных неправильных ответов
подряд могут пройти проверку.
